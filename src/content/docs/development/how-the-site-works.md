# How the Site Works

Astro docs site. All content is Markdown files in `src/content/docs/`, organized into subdirectories (overview, program, advice, misc, development). Each `.md` file needs `title` frontmatter (plus optional `date` and `order` for sorting).

- **Pages**: `src/pages/index.astro` renders `overview/about.md` at the root. `src/pages/[...slug].astro` generates a page for every doc.
- **Sidebar**: Defined in `src/sidebar.config.ts`. Groups auto-populate from their directory via `autogenerate`.
- **Layout**: Single `DocsLayout.astro` wraps all pages. One shared `Sidebar.astro` component.
- **Content collection**: Configured in `src/content.config.ts` — globs all `**/*.md` under `src/content/docs`.

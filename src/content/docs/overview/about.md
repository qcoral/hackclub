# About

This is a page containing various philosophy documents about running hardware programs at Hack Club. Most of these are internal memos I circulated around.

If you're ever interested in contributing, or are just curious as to what the bigger picture is, I recommend reading through these!

I want to preface that the tone, perspective, and style of each document may change! consider this more of an archive and for each document to be taken individually, rather than some cohesive list
